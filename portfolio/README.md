# Akshita Jain — Portfolio Website

## Folder Structure
```
portfolio/
├── index.html                  ← Main file (open this in browser)
├── assets/
│   ├── images/
│   │   ├── profile.jpg         ← Your hero photo
│   │   └── projects/
│   │       ├── brand-work.jpg  ← Replace with real screenshot
│   │       ├── agf.jpg         ← Replace with real screenshot
│   │       ├── meta-ads.jpg    ← Replace with real screenshot
│   │       ├── sscbs.jpg       ← Replace with real screenshot
│   │       ├── german.jpg      ← Replace with real screenshot
│   │       └── glgv.jpg        ← Replace with real screenshot
```

## To update project images
Replace any .jpg in assets/images/projects/ with your own screenshots.
Keep the same filename so the HTML links work automatically.

## To go live
Upload to Netlify, GitHub Pages, or Vercel — drag & drop the folder.
